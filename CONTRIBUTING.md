# Contributing to Vectora

Thanks for helping make mathematics more intuitive. Before opening a pull request:

1. Keep the product focused on learning through interaction.
2. Use TypeScript types for component props and mathematical data.
3. Separate calculation logic from UI components.
4. Add tests for mathematical functions and edge cases as the compute layer is introduced.
5. Preserve keyboard access, visible focus, reduced-motion support, and responsive layouts.
6. Run `npm run build` before submitting.

For substantial features, open an issue first with the learning goal, interaction design, mathematical assumptions, and a short validation plan.
