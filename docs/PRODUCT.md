# Product brief

## One-line vision

Vectora makes linear algebra tangible through interactive experiments and visual explanations.

## Audience

- Students encountering linear algebra for the first time
- Engineering students using matrices in mechanics, graphics, robotics, and signals
- Learners studying machine learning and data science
- Curious builders who want to inspect how algorithms work

## Core promise

**Change a mathematical object and see what changes, why it changes, and where the idea is useful.**

## Experience principles

- Start with a useful interaction rather than a wall of theory.
- Show definitions and assumptions next to results.
- Use visual intuition alongside precise notation.
- Let users experiment without creating an account.
- Distinguish conceptual illustrations from validated numerical computation.
- Make the interface usable on laptops, tablets, and phones.

## Initial release scope

The initial public shell contains a branded landing page, a matrix operation preview, a product roadmap, and architecture/deployment documentation. It is an early foundation, not yet a complete course or a production scientific calculator.

## Explicit non-goals for the first release

- User accounts, cloud-saved workspaces, or progress tracking
- Claiming complete numerical-analysis coverage
- Replacing NumPy, SciPy, MATLAB, or a symbolic mathematics system
- Unreviewed AI-generated mathematical explanations presented as authoritative
- Shipping an API before its schemas, numerical behavior, and tests are ready

## Product health indicators to add later

- First successful operation
- Completion rate for guided experiments
- Repeat use of a learning module
- Accessibility and mobile usability findings
- Calculation correctness and regression coverage
